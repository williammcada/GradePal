# GradePal — Foundation Learner Model

**Status:** Product direction; no source implementation is asserted.

## Intended capability

GradePal maintains persistent student-by-standard mastery, provides an individual dashboard and parent-facing reports, and may later provide differentiation signals to MathQuest. The first build must define its own local data model, access model, retention policy, and integration boundary before any connection is made to other products.

## Non-goals for the foundation

- No implied shared account system with MathQuest, TestForge, or DataDiver.
- No automatic collection or synchronization of student data.

## Acceptance checks

| Check | Result |
| --- | --- |
| Mastery state, reporting, and correction rules are explicitly defined | Not run |
| Any future integration has an approved data contract | Not run |
